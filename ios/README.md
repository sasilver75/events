# ios/

Xcode project root for the Spur iOS app (Swift / SwiftUI).

Populated by [issue #3](https://github.com/sasilver75/events/issues/3): iOS
bootstrap — Xcode layout, SPM split, MapLibre integration, min iOS, and a
SwiftUI shell with map.

See [`PRD-v0.md`](../PRD-v0.md) for product spec,
[`docs/adr/`](../docs/adr/) for architectural decisions, and
[`CLAUDE.md`](../CLAUDE.md) for project conventions.
